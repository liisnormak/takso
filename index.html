        DAX-mõõdikud

        Suure hälbe osakaal. See mõõdik arvutab sissejuhatuses defineeritud suure hälbe osakaalu. Kehtetud sõidud ja lubatud hinnata tellimused on välja jäetud.

        Suure hälbe osakaal =
VAR kehtivad =
    FILTER ( dim_tellimus,
        dim_tellimus[kehtetu] = FALSE ()
            && NOT ISBLANK ( dim_tellimus[lubatud_hind] ) )
RETURN
    DIVIDE (
        COUNTROWS ( FILTER ( kehtivad,
            ABS ( dim_tellimus[loppuhind] - dim_tellimus[lubatud_hind] )
                / dim_tellimus[lubatud_hind] > 0.2 ) ),
        COUNTROWS ( kehtivad ) )

        Kaebuste määr. See mõõdik arvutab ülemaksu kaebusega tellimuste osakaalu kehtivatest tellimustest.

        Kaebuste määr =
DIVIDE (
    CALCULATE ( COUNTROWS ( dim_tellimus ),
        dim_tellimus[ulemaksu_kaebus] = 1,
        dim_tellimus[kehtetu] = FALSE () ),
    CALCULATE ( COUNTROWS ( dim_tellimus ),
        dim_tellimus[kehtetu] = FALSE () ) )
